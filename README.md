# CDTM Hackathon

Fullstack app scaffold with a React frontend and an Express backend.

## Structure

```text
apps/
  frontend/   React + Vite + TypeScript
  backend/    Express + TypeScript
```

## Getting Started

```bash
npm install
npm run dev
```

Frontend: http://localhost:5173

Backend: http://localhost:3000

## Useful Scripts

```bash
npm run dev
npm run build
npm run dev:frontend
npm run dev:backend
```
